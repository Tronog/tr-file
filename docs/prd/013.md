# Overview (disk usage)
We are implementing `disk-usage` sub-app.
It has workbensh for panels.
Each panel can have one of these components:
* disk usage visualization

# Section 1 (backend)
Disk usage will be calculated in backend.
It is a long running process.
It will report back to UI every 3 seconds.
It will go deep in folder tree (max 100 levels).


# Section 2 (components)
## Section 2.1 (disk usage visualization)
This component will visualize the usage in folder.
Component will have location bar same as file-browser with same UX.
Component will have a toolbar for switching between vizualizations and depth of vizualization.
Type of vizualization:
* pie chart
* table with percentage bar
* rectangles

## Section 2.1.1 (controls)
We should be able to abort current process with button in toolbar or `Esc`.
