# Overview (panels - general)

# Section 1 (panels)
Implement UI interactivity of panels.

## Section 1.1 (maximize)
Double-click on tab should maximize/unmaximize the tab group.

## Section 1.2 (remember positions)
Panel state (positions, size, paths, ...) should be remembered between sessions. Use localStorage for that.

## Section 1.3 (initial state)
The initial state should be two panels side by side.

# Section 2 (panel keyboard navigation)
Implement traditional keyboard navidation when focused inside panel.
Create a feature class.

## Section 2.1 (back)
Alt-left/alt-right should go back/forward in history (history of visited paths) for that particulat panel.
Make sure if folder is empty, it still works.
Create a feature class.

## Section 2.2 (split & close)
Ctrl-T should split panel horizontally.
Ctrl-W closes currently focused tab.

## Section 2.3 (up)
Alt-up should move you up the directory tree.

## Section 2.4 (next/prev)
Ctrl-PgUp/PgDown focused next/previous tab.

## Section 2.5 (open in new panel)
Ctrl-Enter opens folder/file in newly split panel on the right.
Also Ctrl-double click does the same.

## Section 2.6 (navigation)
Ctrl-Tab/Shift-Ctrl-Tab jumps between panels and panes.
Tab/Shift-Tab jumps between panels only.

## Section 2.7 (active, previous)
We need to remember which panel is active and which panel was active before (just 1 level deep).
This is important, since we might have three or more panels visible, and this way we can determine file actions source and destination paths. Source is current focused panel, destination is panel that was in focus before before.

### Section 2.7.1
Show active (source) and previous (destination) path in `Details` `Actions` at the end with a little bit of padding on top.

# Section 3 (panel focus)
When clicking on tab, the panel content should get in focus after becomes visible.
Create a feature class.

## Section 3.1 (panel focus)
When clicking on an empty area of a panel, it should put it in focus and it's content should get in focus.
After clicking on table header for sorting, the focus shoud go on content below.
If nothing is selected, then the first item should become selected.

# Section 4 (modal)
Implement module for modal windows that will behave and look as similarly as possible to VS Code's modal experience.

# Section 5 (explorer and details panes)
## Section 5.1 (movable)
we should be able to drag&drop to rearange the collapsable sections inside `Explorer` and `Details` panes.
