# Overview (design)
We are creating a file manager app.

# Section 1
Create a mockup.
Use VisualStudio Code as inspuration.
We want UI elements and design to be as close as possible.
We want left and right sidebars. Left for directory tree. Right for directory/file details.
in the middle there will be panels, with tabs on top. Panels are movable, groupable, divisible, adjustable by dragging borders.
Interactivity will be done in future. Only design for now.


# Section 2
Create surrounding pnpm monorepo workspace environment


# Section 3
Create backend.


# Section 4
Use angular-developer and angular-new-app skills.
Create frontend app with just blank white page.
Rest will come later.


# Section 5
Create docker compose environments.


# Section 6
Port UI mockup from `Section 1` into frontend Angular layer.
All data must be in services prefixed as MockData.
In future, real data will be used from backend.

Create a component library with Angular best practices and absolute most modern patterns with zoneless and signals.

## Section 6.1 (panels)
Implement UI interactivity of panels.

## Section 6.2 (panel keyboard navigation)
Implement traditional keyboard navidation when focused inside panel.
Create a feature class.

## Section 6.2.1 (back)
Alt-left/alt-right should go back/forward in history (history of visited paths) for that particulat panel.
Make sure if folder is empty, it still works.
Create a feature class.

### Section 6.3 (panel focus)
When clicking on tab, the panel content should get in focus after becomes visible.
Create a feature class.

#### Section 6.3.1 (panel focus)
When clicking on an empty area of a panel, it should put it in focus and it's content should get in focus.


# Section 7
This is full-stack. We are creating file-system access service in frontend and API in backend.
Backend should be available under `/api/fs/`.
Functionality shoul be:
* directory listing
* directory/file details
* file download
* file upload
Focus is on backend functionality and frontend services functionalify. UI wiring will be done later.

## Section 7.1
Wire the `Section 7` with workbench UI.

## Section 7.2
Wire `explorer` sidebar with panels in such a way that whenever we click on folder in `explorer`, the active panel would show content of tat folder.
Create a separate feature class for that.

## Section 7.3
Double click on file in `explore` should open new tab and open read-only content of file. If it's markdown, it should show rendered version.
Create a separate feature class for that.


# Section 8
Create an electron app that will be able to run the whole stack.

## Section 8.1
We want to eliminate the HTTP communication layer when using desktop version and communicate with backend directly. Create separate module for backend and separate service in frontend.

## Section 8.2 (window decorations)
We want window without window decorations. we want buttons to be incorporated in top menubar, the way VSCode does it.
Create a feature class.
