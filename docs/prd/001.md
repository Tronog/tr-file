# Overview (design)
We are creating a file manager app.

# Section 1
Create a mockup.
Use VisualStudio Code as inspuration.
We want UI elements and design to be as close as possible.
We want left and right sidebars. Left for directory tree. Right for directory/file details.
in the middle there will be panels, with tabs on top. Panels are movable, groupable, divisible, adjustable by dragging borders.
Interactivity will be done in future. Only design for now.

# Section 3

# Section 4

# Section 5

# Section 6
Port UI mockup from `Section 1` into frontend Angular layer.
All data must be in services prefixed as MockData.
In future, real data will be used from backend.

Create a component library with Angular best practices and absolute most modern patterns with zoneless and signals.

# Section 7
This is full-stack. We are creating file-system access service in frontend and API in backend.
Backend should be available under `/api/fs/`.
Functionality shoul be:
* directory listing
* directory/file details
* file download
* file upload
Focus is on backend functionality and frontend services functionalify. UI wiring will be done later.

## Section 7.1
Wire the `Section 7` with workbench UI.

## Section 7.2
Wire `explorer` sidebar with panels in such a way that whenever we click on folder in `explorer`, the active panel would show content of tat folder.
Create a separate feature class for that.

## Section 7.3
Double click on file in `explore` should open new tab and open read-only content of file. If it's markdown, it should show rendered version.
Create a separate feature class for that.

### Section 7.3.1
There should be an image viewer. 
Default zoom should be contain.
It should have controls for zoom: `+`, `-`, `100%`, `cover`, `contain` - icons, not text. 
It should be able to zoom with scroll wheel. 
If zoomed, mouse drag should pan image. Double click should zoom out to contain.
Create separate component, with separate service.
