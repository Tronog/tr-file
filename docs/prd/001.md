## Section 8.5 (visibility shortcut)
Ctrl-` (ctrl tilda) toggles window visibility. Shortcut is global.

## Section 8.6 (self updating)
We want to implement application auto update.
We want distributables in:
- (windows) - S:\Library\Software\Applications\Tronog\TR-File - *.exe
- (linux) - /S/Library/Software/Applications/Tronog/TR-File - *.AppImage
Key whether file is new version is file name, size, modify time.
When update is available, we want to show a blue `Upgrade` button in window title bar on right side of command pallete input box.

### Section 8.6.1 (self updating)
Add menu option under `File` to manually check if updates exist.
