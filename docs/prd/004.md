# Section 2 (midnight-commander)
We want a subset for behavior of midnight-commander to be also in this app.
In bottom in status bar we want in the middle to show a strip with function commands shown.
Also we want those shortcuts to be mapped to real functionality (F2, F3, F4, F5...).

We also want:
- `*` to toggle select all
- `insert` to toggle select item and move forward
- `+`, `-` - select/unselect by pattern

# Section 3 (optimization)
## Section 3.1 (large folders)
We are countering the slowdown or halt when we open folder with milions of files.
When folder has less than 1000 files, behavior stays the same.
When there are more, we need an on-demand behavior that is performed in worker.
It should first get item count.
Then their names.
Then it shows the content, with no details yet.
Asynchronously the app gets rest of the data about files in background.
Fetching should be in batches, not per single item.
Update should be once per second until fetch is done.
