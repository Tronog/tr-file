# Overview (file operations)
We want to implement major file operations:
* copy
* move
* move to trash
  * empty trash

# Section 1
Implement those actions in backend.
* On desktop use desktop shell versions if connected to local machine.
* On remote connection, it has to be done by backend.
  Create a separate backend module for file actions. 
  Backend actions will be long running actions, that return progress on 1 second basis, so that it does not overwhelm the UI and communication channel.
  They also have to be abortable.
  In UI, the modal window should show progress.
  There should be progress in `bottom-panel` in `Progress` tab.

For delete action, there must be a dialog box for confirmation of action!

# Section 2 (drag and drop, copy paste)
In `file-browser` component, implement copy/paste for files and directories. It should behave same as with any other file manager in the same panel or across panels.

Also implement drag & drop within panel or between panels.
