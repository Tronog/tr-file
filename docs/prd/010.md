# Overview (settings modal)
There should be a settings modal, inspired by VS Code.

# Section 1
Build the skeleton for settings modal.
It should have these modules:
* general
* appearance
* keyboard shortcuts

# Section 2
Make all hardcoded shortcuts configurable. Make them available in `keyboard-shortcuts` settings page.

# Section 3
Make `Explorer` and `Details` panes position (left or right) configurable.
Positions of them are not exclusive, they can both be on same side.

# Section 4 (visual)
We want dark (current) and light theme. Use current VS Code as inspiration.
